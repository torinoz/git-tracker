Connect your GitHub

Git Tracker needs a GitHub access key (a "personal access token") to see who has access to your repositories. The key stays in this browser and is only ever sent to GitHub.

  1. Open this GitHub page (sign in if asked).
  2. "repo" is already ticked. Pick an expiration date you're comfortable with.
  3. Scroll down, click Generate token, and copy the token (it starts with ghp_).
  4. Paste it below.

Without your key, this page shows nothing. Nobody who opens it can see your repositories. It only reads from GitHub and never changes anything.
