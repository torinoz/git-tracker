Connect your GitHub

Git Tracker needs a GitHub access key (a "personal access token") so it can see who has access to your repositories. It's saved only on this computer.

  1. Open this GitHub page (sign in if asked).
  2. "repo" is already ticked. Pick an expiration date you're comfortable with.
  3. Scroll down, click Generate token, and copy the token (it starts with ghp_).
  4. Paste it below.

This app only runs on your PC at 127.0.0.1, so nobody else can open it. It only reads from GitHub and never changes anything.
